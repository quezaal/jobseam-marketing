Jobs and Talent email intake

Connect Jobs and Talent sources

Open Settings and configure each source for its own purpose. Jobs intake processes vendor requirements. Talent intake processes resumes and related candidate email. Confirm the mailbox, folder and routing for each source.

Import older email

For Jobs, set Fetch since, save the source and choose Rescan. It checks read and unread messages from the saved date, including that day. If the date is blank, it checks the past 14 days. A regular Jobs poll checks unread email in the configured folder. Review imported requirements in Requirements Inbox. For Talent, review processed résumés and exceptions in Talent Intake.

Investigate zero imports

A connection test checks mailbox access. To diagnose zero imports, check the folder, date, sender rules and source logs. A successful unread poll can return zero even when the folder contains older read messages. Run a dated rescan for those messages and compare the scan count with the items in the review queue.
