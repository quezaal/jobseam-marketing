Jobs and Talent email intake

Connect Jobs and Talent sources

Open Settings and configure each source for its own purpose. Jobs intake processes vendor requirements. Talent intake processes resumes and related candidate email. Confirm the mailbox, folder and routing for each source.

Import older email

Save the supported historical start date and request a rescan. Routine polling can have different selection rules, such as unread or new messages. Verify imported items in the appropriate review queue.

Investigate zero imports

Check the source, folder, time window and eligible messages. A successful poll can return zero imports. Compare actual queue items and recorded errors before changing the start date.
